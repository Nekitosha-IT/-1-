# ЕГАИС — внешняя обработка 1С

Проект внешней обработки `.epf` для 1С:Розница 2.3.

## Первый модуль

**Отмена решения по ЕГАИС ТТН** через `RequestRepealWB`.

Обработка рассчитана на работу с локальным УТМ. Адрес УТМ задаётся в форме и по умолчанию не зашит в коде.

## Сборка

Требуется 1С:Предприятие 8.3.27.2130 или совместимая версия с поддержкой внешних обработок.

```powershell
cd .\epf
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\build-epf.ps1
```

Готовый EPF появится в каталоге `epf\dist`.

## Важно

`WBRegId` — это идентификатор ТТН ЕГАИС, а не печатный номер накладной.
