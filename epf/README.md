# ЕГАИС — распроведение входящих ТТН

Внешняя обработка для 1С Розница 2.3 (управляемое приложение).

## Сборка

Требуется 1С:Предприятие 8.3.27.2130 и инфобаза `localhost\\roz2026`.

Запуск из PowerShell:

```powershell
cd C:\EGaisMarkLoader
git fetch origin main
git reset --hard origin/main
cd .\epf
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\build-epf.ps1
```

Скрипт собирает:

`epf\\EgaisCancelledTTN2026.xml` -> `epf\\dist\\EgaisCancelledTTN2026.epf`

Для автоматической сборки без запроса логина/пароля можно задать:

```powershell
$env:EGAIS_1C_USER = 'имя_пользователя'
$env:EGAIS_1C_PASSWORD = 'пароль'
```

## Что делает обработка

- проверяет доступность УТМ по `/diagnosis`;
- позволяет выбрать проведённые документы `ЕГАИСЗаказ`;
- показывает номер, дату, поставщика и статус;
- снимает проведение через `РежимЗаписиДокумента.ОтменаПроведения`;
- обрабатывает ошибки по каждой накладной;
- показывает итог по обработанным документам;
- не изменяет конфигурацию и не требует внешних компонент.

## Важно

Автоматическое распроведение связанных `ПоступлениеТоваровУслуги` намеренно не выполняется без подтверждённой связи в конкретном релизе Розницы 2.3. Обработка не должна самовольно менять связанный документ.
